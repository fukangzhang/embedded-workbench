# 主机仿真告警输出状态展示

## Goal
让主机仿真和状态响应能展示告警输出策略，使学习者可以顺着 `sensor_sample -> alarm_state -> alarm_output` 看到完整业务链路。

## Scope
- 在响应格式中增加告警输出字段。
- 在 `host_sim` 默认演示中打印告警输出。
- 补充对应测试和学习说明。

不在本任务中接入真实 GPIO、蜂鸣器、继电器或板上驱动。

## Steps
1. 扩展状态响应，让它包含 indicator、buzzer、actuator 和 period。
2. 更新主机仿真默认输出，演示每个样本对应的输出策略。
3. 更新测试，固定新的输出格式。
4. 更新学习文档，说明这一步如何对应代码。

## Validation
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- 固件 ELF 构建保持通过。

## Open Questions
- 后续是否把输出策略接到独立 actuator driver，由后续任务决定。
