# 目标
实现环境监测项目的第一版告警状态机，让系统可以根据传感器样本和阈值配置输出 `NORMAL`、`WARNING`、`ALARM`、`SENSOR_FAULT` 状态。

## 范围
- 在 `app/` 中新增告警状态机接口和实现
- 支持温度、湿度、光照、烟雾的预警/告警/恢复阈值
- 无效传感器样本进入传感器故障状态
- 增加状态机单元测试
- 更新 `CMakeLists.txt` 的依赖关系
- 补充告警状态机学习笔记

## 暂不做
- 不做蜂鸣器、LED 或继电器控制
- 不做串口命令配置阈值
- 不接入 FreeRTOS 队列或任务
- 不做复杂滤波或多次采样确认

## 步骤
1. 定义告警状态和阈值配置
2. 实现单次状态更新逻辑
3. 增加正常、预警、告警、故障和恢复测试
4. 接入 CMake 和 CTest
5. 补充学习笔记
6. 运行构建与测试

## 验证方式
- `cmake -S . -B build -G Ninja ...`
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`

## 未决问题
- 真实产品阈值后续需要根据场景调整
- 是否需要多次采样确认告警，留到后续控制策略阶段再定
