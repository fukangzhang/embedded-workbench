# 告警输出节拍逻辑

## Goal
把 `alarm_output_command_t.period_ms` 从展示字段推进成可测试的指示灯节拍逻辑，为后续 FreeRTOS 定时刷新输出做准备。

## Scope
- 新增 `alarm_output_timing` 应用层纯逻辑模块。
- 根据输出命令和经过时间判断 indicator 当前是否点亮。
- 增加主机侧测试覆盖 off、slow blink、fast blink、fault blink 和边界输入。
- 更新学习文档。

不在本任务中修改 FreeRTOS task，也不驱动真实 GPIO。

## Steps
1. 设计 `alarm_output_indicator_is_on` 接口。
2. 实现按周期前半段亮、后半段灭的节拍逻辑。
3. 增加 `test_alarm_output_timing`。
4. 更新 CMake 和学习文档。

## Validation
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `cmake --build build-fw`
- `cmake --build build-fw-rtos --clean-first`
- `cmake --build build-fw-scheduler --clean-first`

## Open Questions
- 后续是否把 `period_ms` 解释为完整周期还是半周期，当前先固定为完整周期。
