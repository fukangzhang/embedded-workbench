# 目标
为后续 STM32 目标板接入准备 CMake 构建结构和工具链说明，让项目区分主机测试构建与目标板库构建。

## 范围
- 调整 `CMakeLists.txt`，增加主机工具和测试构建开关
- 保持默认主机构建行为不变
- 新增 ARM bare-metal 工具链文件
- 使用现有 Zig 工具链做一次 ARM 静态库交叉编译验证
- 补充目标板工具链学习笔记

## 暂不做
- 不生成 `.elf` 固件
- 不加入启动文件和链接脚本
- 不引入 STM32 HAL
- 不下载 ARM GNU Toolchain 到仓库

## 步骤
1. 根据 CMake 官方 toolchain 文件思路整理目标板构建方式
2. 为 host tools/tests 增加 CMake option
3. 新增 `cmake/toolchains/arm-none-eabi.cmake`
4. 新增 `cmake/toolchains/zig-arm-none-eabi.cmake` 作为本机可验证替代
5. 运行主机构建和测试
6. 运行 ARM 静态库交叉编译验证
7. 补充学习文档

## 验证方式
- 主机：`cmake -S . -B build -G Ninja ...`
- 主机：`cmake --build build`
- 主机：`ctest --test-dir build --output-on-failure`
- 目标库：`cmake -S . -B build-arm -G Ninja -DCMAKE_TOOLCHAIN_FILE=cmake/toolchains/zig-arm-none-eabi.cmake -DEW_BUILD_HOST_TOOLS=OFF -DEW_BUILD_TESTS=OFF`
- 目标库：`cmake --build build-arm`

## 未决问题
- 真正的 `arm-none-eabi-gcc` 版本后续根据 ARM 官方发布和本机安装情况确定
- 目标板 `.elf` 构建需要启动文件、链接脚本和 HAL/LL 后再做
