# C代码学习注释补充

## Goal

为当前核心 C 代码补充面向初学者的中文注释，让不熟悉 C 和嵌入式的读者能按模块理解结构、关键指针、状态流转和硬件寄存器访问边界。

## Scope

- 只补充注释和学习索引，不改变代码行为。
- 优先覆盖 `app/`、`drivers/`、`bsp/`、`firmware/`、`tests/` 中的主线文件。
- 大块结构用简短注释，核心逻辑、容易误解的 C 写法和硬件边界给更细说明。

## Steps

1. 检查当前核心 C/H 文件的注释缺口。
2. 补充学习型注释，避免逐行重复解释语法。
3. 更新学习入口，说明“代码内注释”和学习文档如何配合阅读。
4. 运行构建和测试确认行为未变。

## Validation

- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `cmake --build build-fw`
- `cmake --build build-fw-rtos --clean-first`
- `cmake --build build-fw-scheduler --clean-first`
- `git diff --check`

## Open Questions

- 注释密度后续可以按你的阅读反馈继续微调：看不懂的位置继续加，已经很直观的位置保持克制。
