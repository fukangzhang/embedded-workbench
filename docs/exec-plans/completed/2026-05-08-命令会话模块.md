# 命令会话模块

## Goal

新增 app 层 `command_session` 模块，把完整命令行统一处理成响应文本，复用已有 `command_parser`、`command_handler` 和 `response_format`。

## Scope

- 新增 `app/include/.../command_session.h` 和 `app/src/command_session.c`。
- 新增主机测试，覆盖状态查询、配置查询、配置修改、非法命令、输出缓冲不足。
- 接入 `CMakeLists.txt`。
- 更新学习文档和设计边界。
- 不接真实 UART，不改 `host_sim` 行为。

## Steps

1. 写 `tests/test_command_session.c` 固定响应行为。
2. 实现 `command_session` 模块。
3. 接入构建和测试。
4. 补充学习笔记、设计文档和索引。
5. 运行完整验证。

## Validation

- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `cmake --build build-fw`
- `cmake --build build-fw-real-gpio`
- `cmake --build build-fw-rtos --clean-first`
