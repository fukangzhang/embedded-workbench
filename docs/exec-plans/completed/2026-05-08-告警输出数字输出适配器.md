# 告警输出数字输出适配器

## Goal
把 `alarm_output_sink` 接到 `digital_output` 驱动抽象，使告警输出命令可以映射到 board profile 中的 `alarm_led`、`alarm_buzzer` 和 `alarm_actuator`。

## Scope
- 新增 `alarm_output_digital_sink` 应用层适配器。
- 用 fake `digital_output` 测试告警输出到板级引脚的映射。
- 更新 CMake 和学习文档。

不在本任务中实现真实 STM32 GPIO 写入，也不处理 LED 闪烁节拍调度。

## Steps
1. 定义适配器 context 和初始化函数。
2. 实现 indicator、buzzer、actuator 到 `digital_output_write` 的映射。
3. 增加 `test_alarm_output_digital_sink`。
4. 更新文档。

## Validation
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `cmake --build build-fw`
- `cmake --build build-fw-rtos --clean-first`
- `cmake --build build-fw-scheduler --clean-first`

## Open Questions
- `period_ms` 后续由定时器/任务节拍处理，本任务只映射当前输出电平。
