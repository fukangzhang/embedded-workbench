# 告警执行器板级 Profile

## Goal
补齐告警输出策略中的 `actuator` 通道在板级 profile 里的位置，让 indicator、buzzer、actuator 三类输出都有目标板引脚映射。

## Scope
- 在 `board_profile_t` 中增加 `alarm_actuator` 引脚字段。
- 为当前两个 Nucleo profile 增加执行器占位引脚。
- 更新 board profile 测试。
- 更新学习文档，说明 profile 只是硬件假设，不是 GPIO 驱动。

不在本任务中实现真实 GPIO 初始化或输出控制。

## Steps
1. 扩展 `board_profile_t`。
2. 更新 NUCLEO-F401RE 和 NUCLEO-F103RB profile。
3. 更新 `test_board_profile`。
4. 补充学习说明。

## Validation
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `cmake --build build-fw`
- `cmake --build build-fw-rtos --clean-first`
- `cmake --build build-fw-scheduler --clean-first`
