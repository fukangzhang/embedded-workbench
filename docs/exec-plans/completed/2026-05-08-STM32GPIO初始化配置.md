# STM32 GPIO 初始化配置

## Goal
新增一个可主机测试的 STM32 GPIO 初始化配置模块，把 `board_pin_t` 描述的引脚配置为输出模式，为后续真实 GPIO 输出链路补齐 BSRR 写入前的一小块准备工作。

## Scope
- 新增 `stm32_gpio_config` 接口和实现。
- 使用端口名查找模拟的 STM32 GPIO 寄存器块。
- 配置 `MODER`、`OTYPER`、`OSPEEDR`、`PUPDR` 中与目标 pin 对应的位。
- 增加主机测试覆盖输出模式、推挽、速度、上下拉、未知端口和非法参数。
- 更新学习笔记、设计边界和学习 README。

不在本任务中做：
- RCC 时钟开启。
- 真实寄存器基地址绑定。
- HAL/CMSIS 类型接入。
- 板上下载验证。

## Steps
1. 定义 STM32 GPIO 配置寄存器模型。
2. 实现 pin 输出配置函数。
3. 增加主机测试并接入 CMake。
4. 补充学习/设计文档。
5. 运行主机测试和固件构建验证。
