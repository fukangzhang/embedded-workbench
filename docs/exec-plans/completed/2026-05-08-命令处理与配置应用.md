# 目标
实现命令处理层，把解析后的命令应用到告警配置或转换成可执行动作结果，为后续串口响应和主机仿真交互做准备。

## 范围
- 在 `app/` 中新增命令处理接口和实现
- 支持查询状态、查询配置、清除告警、设置阈值的处理结果
- 将 `SET <字段> <数值>` 应用到 `alarm_config_t`
- 拒绝会导致配置非法的阈值修改
- 增加命令处理单元测试
- 补充学习笔记

## 暂不做
- 不生成串口响应字符串
- 不实现实际告警清除锁存
- 不接入 FreeRTOS 队列
- 不做持久化存储

## 步骤
1. 定义命令处理结果类型
2. 实现阈值字段到告警配置的映射
3. 增加成功修改和非法修改测试
4. 接入 CMake 和 CTest
5. 补充学习文档
6. 运行构建与测试

## 验证方式
- `cmake -S . -B build -G Ninja ...`
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`

## 未决问题
- 后续响应格式需要单独设计
- 清除告警是否需要锁存状态，留到控制策略阶段再定
