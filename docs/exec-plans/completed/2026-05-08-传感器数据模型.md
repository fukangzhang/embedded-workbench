# 目标
定义硬件无关的传感器样本数据模型，并提供基础校验逻辑，为后续模拟传感器输入、告警状态机和真实硬件驱动接入做准备。

## 范围
- 在 `drivers/` 中新增传感器样本结构
- 使用适合嵌入式的整数单位表达温湿度、光照和烟雾浓度
- 提供样本初始化和合法性校验函数
- 在 `tests/` 中新增边界测试
- 更新 `CMakeLists.txt` 接入 `embedded_drivers`
- 补充学习笔记解释为什么不用 `float` 作为第一选择

## 暂不做
- 不读取真实传感器
- 不实现告警状态机
- 不实现滤波算法
- 不接入 FreeRTOS 任务

## 步骤
1. 定义 `sensor_sample_t`
2. 实现样本创建和范围校验
3. 为有效样本和无效样本写测试
4. 接入 CMake 和 CTest
5. 补充学习文档
6. 运行构建与测试

## 验证方式
- `cmake -S . -B build -G Ninja ...`
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`

## 未决问题

- 阈值范围后续需要结合产品说明继续细化
