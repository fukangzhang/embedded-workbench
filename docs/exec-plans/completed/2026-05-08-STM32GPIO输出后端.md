# STM32 GPIO 输出后端

## Goal
增加一个可主机测试的 STM32 GPIO 数字输出后端，把 `digital_output` 的高/低电平写入映射为 STM32 常见的 `BSRR` 置位/复位写法。

## Scope
- 新增 `stm32_gpio_output` 驱动接口和实现。
- 使用 `board_pin_t` 的 `port`/`pin` 查找对应 GPIO 端口绑定。
- 写高电平时写 `BSRR` 低 16 位，写低电平时写 `BSRR` 高 16 位。
- 增加主机单元测试覆盖高/低电平、未知端口、无效参数。
- 更新学习文档和设计边界说明。

不在本任务中做：
- RCC 时钟开启。
- GPIO mode/pull/speed 配置。
- 真实 STM32 HAL/CMSIS 接入。
- 板上下载验证。

## Steps
1. 定义 `stm32_gpio_output` 接口。
2. 实现 `digital_output_controller_t` 兼容后端。
3. 增加测试并接入 CMake。
4. 补充学习笔记和设计说明。
5. 运行主机测试和固件构建验证。
