# 数字输出驱动抽象

## Goal
新增一个可主机测试的数字输出驱动抽象，用 `board_pin_t` 表示输出脚，用回调表示实际写 GPIO，为后续把 `alarm_output_sink` 接到真实板级输出做准备。

## Scope
- 新增 `drivers/digital_output` 接口和实现。
- 支持对单个 `board_pin_t` 写高/低电平。
- 用主机 fake 回调测试参数校验、成功写入和失败传递。
- 更新学习文档。

不在本任务中直接接入 `alarm_output_sink`，也不实现 STM32 寄存器或 HAL GPIO 写入。

## Steps
1. 定义 `digital_output_controller_t`、ops 和电平枚举。
2. 实现 `digital_output_write`。
3. 新增 `test_digital_output`。
4. 更新 CMake 和学习说明。

## Validation
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `cmake --build build-fw`
- `cmake --build build-fw-rtos --clean-first`
- `cmake --build build-fw-scheduler --clean-first`

## Open Questions
- 后续真实 STM32 GPIO 实现使用 HAL 还是寄存器级封装，需要目标板接入阶段再定。
