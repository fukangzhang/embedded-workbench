# 目标
新增 GitHub Actions 主机侧 CI，让每个 PR 自动执行 CMake 配置、构建和 CTest，保证核心逻辑改动具备可审查的自动验证入口。

## 范围
- 新增 `.github/workflows/ci.yml`
- 在 Ubuntu 环境安装 `ninja-build`
- 执行 `cmake -S . -B build -G Ninja`
- 执行 `cmake --build build`
- 执行 `ctest --test-dir build --output-on-failure`
- 补充 CI 学习笔记

## 暂不做
- 不加入交叉编译
- 不加入 STM32 固件构建
- 不加入代码覆盖率
- 不加入静态分析

## 步骤
1. 创建 CI workflow
2. 补充学习文档
3. 本地运行现有 CMake/CTest 验证
4. 检查 workflow 文件结构
5. 提交并创建 PR

## 验证方式
- 本地 `cmake -S . -B build -G Ninja ...`
- 本地 `cmake --build build`
- 本地 `ctest --test-dir build --output-on-failure`
- PR 创建后检查 GitHub Actions 是否触发

## 未决问题
