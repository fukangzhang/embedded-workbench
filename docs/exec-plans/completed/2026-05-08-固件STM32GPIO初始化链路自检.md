# 固件 STM32 GPIO 初始化链路自检

## Goal
在 `firmware/src/main.c` 的固件自检中接入 STM32 GPIO 初始化链路，验证固件目标能串起 `RCC clock -> GPIO config -> board profile` 这条初始化路径。

## Scope
- 在固件入口中加入模拟 RCC/GPIO 寄存器变量。
- 初始化 `stm32_rcc_gpio_clock_context_t` 和 `stm32_gpio_config_context_t`。
- 调用 `stm32_board_gpio_init_alarm_outputs` 初始化告警 LED、蜂鸣器、执行器引脚。
- 检查模拟寄存器中的 RCC enable bit 和 GPIO MODER 位。
- 更新学习笔记、设计边界和学习 README。

不在本任务中做：
- 真实 RCC/GPIO 寄存器地址绑定。
- 板上下载验证。
- GPIO 初始电平写入。
- 将 FreeRTOS task 与真实 GPIO 后端绑定。

## Steps
1. 为固件入口增加 STM32 GPIO 初始化自检函数。
2. 将该自检纳入 `firmware_self_check` 判定。
3. 补充学习/设计文档。
4. 运行主机测试和固件构建验证。
