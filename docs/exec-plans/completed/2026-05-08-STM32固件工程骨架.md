# 目标
建立第一版 STM32 bare-metal 固件工程骨架，生成可链接的目标板 `.elf`，为后续接入 STM32 HAL/LL、FreeRTOS 和真实外设初始化做准备。

## 范围
- 新增最小启动文件
- 新增 STM32F401RE 链接脚本
- 新增固件入口 `main`
- 调整 CMake，增加可选 `EW_BUILD_FIRMWARE` 固件目标
- 使用现有核心库链接生成 firmware ELF
- 补充固件工程骨架学习笔记

## 暂不做
- 不引入 STM32 HAL/LL
- 不配置时钟树和外设寄存器
- 不接入 FreeRTOS 内核
- 不生成 `.bin` 或 `.hex`
- 不烧录到真实开发板

## 步骤
1. 参考 STM32F401RE 官方 memory 信息确定 flash/sram 大小
2. 新增 linker script
3. 新增 startup reset/vector table
4. 新增固件 main，调用现有核心逻辑
5. CMake 新增固件构建开关和目标
6. 运行主机测试和 ARM ELF 构建
7. 补充学习文档

## 验证方式
- 主机：`cmake -S . -B build -G Ninja ...`
- 主机：`cmake --build build`
- 主机：`ctest --test-dir build --output-on-failure`
- 固件：`cmake -S . -B build-fw -G Ninja -DCMAKE_TOOLCHAIN_FILE=cmake/toolchains/zig-arm-none-eabi.cmake -DEW_BUILD_HOST_TOOLS=OFF -DEW_BUILD_TESTS=OFF -DEW_BUILD_FIRMWARE=ON`
- 固件：`cmake --build build-fw`

## 未决问题
- 当前 ELF 只是工程骨架，未包含真实系统时钟、HAL 初始化和中断处理
- 后续需要使用真实 ARM GNU Toolchain 与开发板烧录验证
