# 目标
升级主机仿真程序，让它可以演示传感器样本、告警状态机和命令处理的基本闭环。

## 范围
- `host_sim` 默认输出一组模拟传感器样本和告警状态
- 支持 `--script` 模式，从标准输入读取命令
- 命令可查询状态、查询配置、设置阈值和请求清除告警
- 增加 `host_sim` smoke 测试
- 补充学习笔记

## 暂不做
- 不做持续实时循环
- 不做复杂交互 UI
- 不接入真实串口
- 不接入 FreeRTOS

## 步骤
1. 为 `host_sim` 接入传感器样本、告警状态机和命令处理
2. 增加默认演示输出
3. 增加 `--script` 命令输入模式
4. 接入 CTest smoke 测试
5. 补充学习文档
6. 运行构建与测试

## 验证方式
- `cmake -S . -B build -G Ninja ...`
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `build/host_sim.exe`
