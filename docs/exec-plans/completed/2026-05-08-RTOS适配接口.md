# 目标
建立第一版 RTOS 适配接口，把应用层任务逻辑与未来 FreeRTOS API 隔离开，为后续接入真实 FreeRTOS 内核做准备。

## 范围
- 在 `app/` 中新增 RTOS port 接口
- 提供主机 fake RTOS port 实现，用于测试
- 定义启动任务、发送传感器样本、发送命令、接收响应等最小接口
- 增加 RTOS port 测试
- 补充学习文档

## 暂不做
- 不引入 FreeRTOS 内核源码
- 不调用真实 `xTaskCreate` 或 `xQueueSend`
- 不实现真正多任务调度
- 不修改 firmware startup

## 步骤
1. 定义 RTOS port 操作表
2. 实现主机 fake port
3. 增加接口调用和错误路径测试
4. 接入 CMake/CTest
5. 补充学习文档
6. 运行主机测试和固件构建

## 验证方式
- 主机：`ctest --test-dir build --output-on-failure`
- 固件：`cmake --build build-fw`

## 未决问题
- 真实 FreeRTOS port 的队列句柄和任务句柄结构，等引入内核源码后再定
