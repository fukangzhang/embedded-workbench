# 告警输出 Sink 接口

## Goal
在告警输出策略和真实硬件控制之间增加一个小接口，使 `alarm_output_command_t` 可以被应用到抽象输出目标，为后续 GPIO、蜂鸣器和执行器驱动接入留出稳定边界。

## Scope
- 新增 `alarm_output_sink` 应用层接口。
- 用主机侧 fake 回调测试接口行为。
- 让 FreeRTOS 告警输出任务在收到告警事件后可以选择性调用 sink。
- 补充学习文档，说明策略、sink、真实硬件之间的关系。

不在本任务中实现真实 STM32 GPIO 或具体引脚控制。

## Steps
1. 设计 `alarm_output_sink_t` 和回调操作表。
2. 实现 `alarm_output_sink_apply`。
3. 增加 `test_alarm_output_sink`。
4. 在 FreeRTOS context 中增加可选 sink，并在告警输出 task 中调用。
5. 更新学习文档和计划记录。

## Validation
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `cmake --build build-fw`
