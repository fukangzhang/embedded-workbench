# 目标
实现第一版串口风格命令解析器，让项目可以识别查询状态、查询配置、设置阈值和清除告警等文本命令。

## 范围
- 在 `drivers/` 中新增命令解析接口和实现
- 支持 `STATUS?`、`CONFIG?`、`CLEAR_ALARM`
- 支持 `SET <字段> <数值>` 形式的阈值设置命令
- 增加命令解析单元测试
- 更新 `CMakeLists.txt`
- 补充通信命令学习笔记

## 暂不做
- 不直接修改告警配置
- 不实现串口收发驱动
- 不实现响应格式
- 不接入 FreeRTOS 通信任务

## 步骤
1. 定义命令类型、阈值字段和命令结构
2. 实现文本命令解析
3. 覆盖合法命令和非法输入测试
4. 接入 CMake 和 CTest
5. 补充学习文档
6. 运行构建与测试

## 验证方式
- `cmake -S . -B build -G Ninja ...`
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`

## 未决问题
- 响应协议格式后续单独设计
- 命令是否大小写不敏感，后续根据上位机需求决定
