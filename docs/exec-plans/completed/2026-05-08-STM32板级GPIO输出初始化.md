# STM32 板级 GPIO 输出初始化

## Goal
新增一个板级 GPIO 输出初始化编排模块，把 `board_profile` 中的告警 LED、蜂鸣器和执行器引脚按顺序完成 RCC 时钟使能和 GPIO 输出配置。

## Scope
- 新增 `stm32_board_gpio_init` 接口和实现。
- 使用 `board_profile_t` 的 `alarm_led`、`alarm_buzzer`、`alarm_actuator` 作为初始化目标。
- 对每个目标 pin 执行：打开 GPIO 端口时钟 -> 配置为输出模式。
- 增加主机测试覆盖成功路径、默认输出配置、重复端口、失败路径。
- 更新学习笔记、设计边界和学习 README。

不在本任务中做：
- 真实 RCC/GPIO 寄存器地址绑定。
- 调用 `firmware/src/main.c` 的目标板启动流程。
- GPIO 初始电平写入。
- 板上下载验证。

## Steps
1. 定义板级 GPIO 输出初始化接口。
2. 实现三类告警输出引脚的初始化编排。
3. 增加主机测试并接入 CMake。
4. 补充学习/设计文档。
5. 运行主机测试和固件构建验证。
