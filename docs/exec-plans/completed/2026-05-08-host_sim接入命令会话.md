# host_sim接入命令会话

## Goal

让 `tools/host_sim` 的脚本命令处理复用 `command_session`，避免主机仿真和后续 USART 通信任务各自维护一套命令处理流程。

## Scope

- 修改 `tools/host_sim/main.c`，删除重复的 parser/handler/formatter 编排逻辑。
- 增加一个 host_sim 脚本模式测试，固定 `STATUS?` 输出。
- 更新学习文档，说明 host_sim 现在如何复用 app 层命令会话。
- 不改变命令协议文本格式。

## Steps

1. 修改 host_sim 依赖 `command_session`。
2. 在 CMake 中增加脚本模式测试。
3. 补充学习文档和执行计划记录。
4. 运行完整验证。

## Validation

- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `cmake --build build-fw`
- `cmake --build build-fw-real-gpio`
- `cmake --build build-fw-rtos --clean-first`
- `cmake --build build-fw-scheduler --clean-first`
- `git diff --check`

## Open Questions

- 后续 FreeRTOS communication task 也可以接 `command_session`，本轮先只收敛主机仿真。
