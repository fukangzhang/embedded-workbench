# 板级数字输出后端

## Goal
新增一个基于 `board_profile_t` 的 `digital_output` 后端，用于记录告警 LED、蜂鸣器和执行器三类输出的当前电平，为后续替换成 STM32 GPIO/HAL 实现提供可测试骨架。

## Scope
- 新增 `board_digital_output` 驱动后端。
- 后端识别 `alarm_led`、`alarm_buzzer`、`alarm_actuator` 三类 profile 引脚。
- 支持查询已记录的输出电平。
- 增加主机侧测试和学习文档。

不在本任务中写 STM32 GPIO 寄存器或 HAL 调用。

## Steps
1. 定义 `board_digital_output_context_t` 和初始化函数。
2. 实现 `digital_output_ops_t.write` 后端。
3. 增加 `test_board_digital_output`。
4. 更新 CMake 和学习文档。

## Validation
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `cmake --build build-fw`
- `cmake --build build-fw-rtos --clean-first`
- `cmake --build build-fw-scheduler --clean-first`

## Open Questions
- 后续真实 GPIO 后端是否直接替换此模块，还是新增 `stm32_digital_output` 模块，由目标板接入阶段决定。
