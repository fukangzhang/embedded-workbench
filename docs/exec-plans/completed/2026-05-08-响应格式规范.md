# 目标
定义并实现第一版通信响应格式，让命令处理结果、状态和配置输出不再散落在 `host_sim` 中手写拼接。

## 范围
- 在 `app/` 中新增响应格式化接口和实现
- 支持格式化命令处理结果、状态响应和配置响应
- `host_sim` 使用响应格式化模块输出脚本模式响应
- 增加响应格式单元测试
- 补充学习笔记

## 暂不做
- 不设计二进制协议
- 不加入 CRC、序号或帧头帧尾
- 不接入真实 UART
- 不处理长响应分包

## 步骤
1. 定义响应格式化函数
2. 实现 `OK/ERR`、`STATUS`、`CONFIG` 文本响应
3. 更新 `host_sim` 使用统一响应格式
4. 新增响应格式测试
5. 补充学习文档
6. 运行构建与测试

## 验证方式
- `cmake -S . -B build -G Ninja ...`
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `build/host_sim.exe --script`

## 未决问题
- 后续是否增加帧头、校验和或 JSON 风格响应，等串口链路接入前再定
