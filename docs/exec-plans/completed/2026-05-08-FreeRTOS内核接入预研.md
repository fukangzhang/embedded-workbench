# 目标
建立第一版真实 FreeRTOS-Kernel 外部接入骨架，让固件构建可以选择链接 FreeRTOS 内核源码，为后续实现真实任务和队列做准备。

## 范围
- 新增应用侧 `FreeRTOSConfig.h`
- 新增 CMake 模块，用 `FREERTOS_KERNEL_PATH` 指向外部 FreeRTOS-Kernel
- 新增 `EW_USE_FREERTOS` 构建开关
- 固件构建可选链接 FreeRTOS kernel library
- CI 中临时 clone 官方 FreeRTOS-Kernel 验证固件构建
- 补充 FreeRTOS 内核接入学习笔记

## 暂不做
- 不把 FreeRTOS-Kernel 源码复制进仓库
- 不创建真实任务
- 不调用 `vTaskStartScheduler`
- 不实现真实队列适配
- 不做板上运行验证

## 步骤
1. 参考 FreeRTOS 官方 CMake 和 `FreeRTOSConfig.h` 说明
2. 新增 `FreeRTOSConfig.h`
3. 新增外部 FreeRTOS-Kernel CMake 接线
4. 固件目标可选链接 FreeRTOS kernel
5. 本地 clone 官方 FreeRTOS-Kernel 进行构建验证
6. CI 增加 FreeRTOS firmware build 验证
7. 补充学习文档

## 验证方式
- 主机：`ctest --test-dir build --output-on-failure`
- 固件无 RTOS：`cmake --build build-fw`
- 固件带 RTOS：`cmake --build build-fw-rtos`
- GitHub Actions：主机、固件、FreeRTOS 固件 job 通过

## 未决问题
- 当前默认使用 `GCC_ARM_CM3` port 做 Cortex-M4 非 FPU 上下文保存的初期验证；后续真实启用 FPU 时再切换 `GCC_ARM_CM4F`
- 真实任务创建和队列句柄留到下一阶段
