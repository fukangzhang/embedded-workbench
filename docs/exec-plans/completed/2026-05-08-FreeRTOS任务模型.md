# 目标
建立第一版 FreeRTOS 任务与队列模型描述，在不引入真实 FreeRTOS 源码的情况下，先明确未来目标板上的任务划分、优先级、周期和通信边界。

## 范围
- 在 `app/` 中新增任务模型描述接口和实现
- 定义采集、处理、通信、告警输出任务
- 定义传感器样本、命令、响应、告警事件队列
- 增加任务模型合法性测试
- 补充 FreeRTOS 任务与队列学习笔记

## 暂不做
- 不引入 FreeRTOS 内核源码
- 不调用 `xTaskCreate`、`xQueueCreate`
- 不接入 STM32 BSP
- 不实现真实任务循环

## 步骤
1. 参考 FreeRTOS 官方任务间通信概念
2. 定义任务描述和队列描述
3. 实现模型访问与校验函数
4. 增加单元测试
5. 补充学习文档
6. 运行构建与测试

## 验证方式
- `cmake -S . -B build -G Ninja ...`
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`

## 未决问题
- 真实任务优先级和栈大小后续需要根据 MCU、FreeRTOS 配置和运行观测调整
- 队列长度后续需要根据采样频率、通信速率和内存预算调整
