# 固件真实GPIO初始化开关

## Goal

给固件增加一个默认关闭的编译开关，让 `firmware/src/main.c` 可以在目标板构建中选择使用 STM32F401RE 真实 GPIO/RCC 地址绑定执行告警输出 GPIO 初始化。

## Scope

- 新增 CMake 选项和固件编译宏。
- 默认构建仍保持模拟寄存器自检，避免 CI 或主机环境访问真实 STM32 地址。
- 开关打开时只保证固件能编译链接，并把初始化调用接到真实地址绑定；不声称已经板上验证。
- 更新 CI、学习文档和设计边界说明。

## Steps

1. 增加 `EW_FIRMWARE_USE_REAL_STM32_GPIO_INIT` 选项。
2. 在 `firmware/src/main.c` 中增加真实 GPIO 初始化路径，并默认不启用。
3. 让 CI 构建一次开启该选项的固件 ELF。
4. 补充学习文档和设计记录，说明“编译接线”和“板上验证”的区别。

## Validation

- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `cmake --build build-fw`
- `cmake --build build-fw-rtos --clean-first`
- `cmake --build build-fw-scheduler --clean-first`
- 新增开启真实 GPIO 初始化开关的固件构建
- `git diff --check`
