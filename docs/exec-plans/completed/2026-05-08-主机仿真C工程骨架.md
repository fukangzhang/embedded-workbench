# 目标
建立主机侧可构建、可运行、可测试的最小 `C` 工程骨架，为后续传感器抽象、告警状态机和通信命令解析提供稳定入口。

## 范围
- 补充 `app/` 的最小应用模块
- 补充 `tests/` 的最小测试程序
- 补充 `tools/host_sim/` 的主机仿真入口
- 更新 `CMakeLists.txt`，加入库、可执行文件和 `CTest`
- 补充一篇学习笔记解释 C 工程骨架与主机仿真

## 暂不做
- 不接入真实 `STM32` 工程
- 不引入 `FreeRTOS`
- 不实现真实传感器和告警逻辑
- 不做 Web 前端或上位机界面

## 步骤
1. 定义最小应用接口
2. 增加主机仿真 CLI
3. 增加最小测试程序
4. 接入 CMake 构建目标
5. 补充学习文档
6. 执行可用验证

## 验证方式
- `cmake -S . -B build`
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- 如果本机暂时没有 `cmake`，记录环境问题并至少检查文件结构与 Git 状态
