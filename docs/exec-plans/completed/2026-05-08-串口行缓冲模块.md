# 串口行缓冲模块

## Goal

新增一个可主机测试的串口行缓冲模块，把逐字节输入组装成一行命令，为后续 USART2 / ST-LINK VCP 通信接入做准备。

## Scope

- 新增 `drivers` 层 `serial_line` 模块。
- 支持普通字符追加、`\n`/`\r` 行结束、空行忽略、缓冲区溢出检测和复位。
- 新增主机侧单元测试。
- 更新学习文档和设计边界。
- 不接真实 UART，不改现有 host_sim 行为。

## Steps

1. 先写 `tests/test_serial_line.c` 固定行为。
2. 实现 `drivers/include/.../serial_line.h` 和 `drivers/src/serial_line.c`。
3. 接入 `CMakeLists.txt`。
4. 补充学习笔记、设计记录和学习索引。
5. 运行构建与测试。

## Validation

- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `cmake --build build-fw`
- `cmake --build build-fw-rtos --clean-first`
- `cmake --build build-fw-scheduler --clean-first`
- `git diff --check`

## Open Questions

- 后续真实 USART 接入时，换行规则是否需要兼容更多终端行为，本轮先覆盖 `\n`、`\r` 和 `\r\n` 的常见情况。
