# 固件告警输出链路自检

## Goal
让目标板固件入口也实际走到 `alarm_output -> alarm_output_digital_sink -> digital_output -> board_digital_output` 链路，确保硬件输出前置骨架不仅在主机测试里存在，也被固件 ELF 构建覆盖。

## Scope
- 在 `firmware/src/main.c` 增加告警输出链路自检。
- 复用 `board_profile_default()`、`board_digital_output` 和 `alarm_output_digital_sink`。
- 验证 `ALARM_STATE_ALARM` 能映射到 LED、蜂鸣器、执行器高电平。
- 更新学习文档。

不在本任务中启动真实 GPIO、HAL 或闪烁节拍。

## Steps
1. 在固件入口添加相关头文件和静态 context。
2. 增加 `firmware_alarm_output_self_check`。
3. 将自检结果纳入 `firmware_self_check` 成功条件。
4. 更新学习说明。

## Validation
- `cmake --build build`
- `ctest --test-dir build --output-on-failure`
- `cmake --build build-fw`
- `cmake --build build-fw-rtos --clean-first`
- `cmake --build build-fw-scheduler --clean-first`
