# 目标
完成项目的第一阶段定义工作，把“我们到底要做什么、先做什么、为什么这么做”写清楚，并为后续代码开发准备好分支和文档基础。

## 范围
- 明确项目题目和求职定位
- 用中文统一项目核心文档
- 写清楚第一阶段的任务边界
- 为后续功能开发建立活动计划入口

## 步骤
1. 整理项目的中文说明文档
2. 明确项目目标、核心功能和开发策略
3. 明确第一阶段不做什么，避免发散
4. 准备下一阶段功能分支计划

## 验证方式
- 检查 `README.md`、`AGENTS.md`、`ARCHITECTURE.md`、`WORKFLOW.md` 是否已统一为中文
- 检查 `docs/product-specs/项目说明.md` 是否能清楚说明项目定位
- 使用 `git status --short --branch` 检查改动范围

## 当前阶段暂不做

- 不急着引入完整 `FreeRTOS` 源码
- 不急着做复杂上位机界面
- 不急着引入过多第三方框架
