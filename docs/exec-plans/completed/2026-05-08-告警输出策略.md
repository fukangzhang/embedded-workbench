# 目标
新增告警输出策略纯逻辑模块，把 `alarm_state_t` 映射为 LED/蜂鸣器/执行器等输出命令，为后续硬件输出和 FreeRTOS 告警输出任务做准备。

## 范围
- 新增 `alarm_output` app 模块
- 定义告警输出命令结构
- 将 normal/warning/alarm/sensor_fault 映射到明确输出模式
- 增加 host 单元测试
- 补充学习笔记

## 暂不做
- 不接真实 GPIO/PWM
- 不接 LED、蜂鸣器或继电器驱动
- 不改 FreeRTOS 任务函数
- 不做板上验证

## 步骤
1. 新增 `alarm_output` 头文件和源文件
2. 增加 `alarm_output_command_for_state` 映射函数
3. 增加 host 测试覆盖所有状态和错误路径
4. 接入 CMake/CTest
5. 运行 host 测试和固件构建
6. 更新学习文档并归档计划

## 验证方式
- 主机：`cmake --build build --target test`
- 固件无 RTOS：`cmake --build build-fw`
- 固件带 RTOS：`cmake --build build-fw-rtos --clean-first`
- GitHub Actions：主机、固件、FreeRTOS 固件 job 通过

## 未决问题
- 具体 LED、蜂鸣器、继电器引脚要等 BSP/硬件输出层接入后再定
- 输出节奏后续可能根据产品说明继续调整
