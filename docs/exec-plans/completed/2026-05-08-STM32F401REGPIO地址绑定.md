# STM32F401RE GPIO 地址绑定

## Goal
新增 STM32F401RE 的 RCC/GPIO 地址绑定薄层，为后续把固件自检从模拟寄存器迁移到真实寄存器地址做准备。

## Scope
- 新增 `stm32f401re_gpio_bindings` 接口和实现。
- 暴露 `RCC_AHB1ENR`、`GPIOA/GPIOB` 配置寄存器块和 `BSRR` 的绑定表。
- 增加主机测试验证地址常量、端口名和 bit 绑定关系。
- 更新学习笔记、设计边界和学习 README。

不在本任务中做：
- 在 `firmware/src/main.c` 中解引用真实寄存器地址。
- 板上下载运行。
- 引入 CMSIS/HAL 头文件。
- 覆盖所有 GPIO 端口。

## Steps
1. 定义 STM32F401RE RCC/GPIO 地址绑定接口。
2. 实现 PA/PB 相关绑定表。
3. 增加主机测试并接入 CMake。
4. 补充学习/设计文档。
5. 运行主机测试和固件构建验证。
