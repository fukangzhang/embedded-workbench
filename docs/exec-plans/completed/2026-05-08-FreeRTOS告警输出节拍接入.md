# FreeRTOS 告警输出节拍接入

## Goal
让 FreeRTOS 告警输出任务使用 `alarm_output_timing`，根据 `period_ms` 周期刷新 indicator 亮灭，为后续真实 GPIO 输出和闪烁效果做准备。

## Scope
- 在 `rtos_port_freertos` 的告警输出 task 中保留当前告警输出命令。
- 收到新告警事件时重置 elapsed time。
- 周期性调用 `alarm_output_indicator_is_on`，将 indicator 转成当前亮/灭状态后应用到 sink。
- 更新学习文档。

不在本任务中做板上运行验证，也不引入真实 GPIO/HAL。

## Steps
1. 引入 `alarm_output_timing`。
2. 为告警输出 task 增加定时刷新逻辑。
3. 保持构建级验证通过。
4. 更新学习说明。
