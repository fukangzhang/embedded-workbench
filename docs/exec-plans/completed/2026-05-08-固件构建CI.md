# 目标
扩展 GitHub Actions，让 CI 不仅跑主机测试，也验证 STM32 固件骨架可以生成 `embedded_firmware.elf`。

## 范围
- 在 `.github/workflows/ci.yml` 新增 firmware build job
- CI 中安装 `ziglang` Python 包作为临时 ARM freestanding 工具链
- 创建 `zig ar` 和 `zig ranlib` wrapper
- 运行固件 CMake 配置和构建
- 补充固件构建 CI 学习笔记

## 暂不做
- 不在 CI 中烧录开发板
- 不上传 `.elf` artifact
- 不使用真实 ARM GNU Toolchain
- 不加入 `.bin`/`.hex` 生成

## 步骤
1. 扩展 CI workflow
2. 补充学习文档
3. 本地复跑主机测试
4. 本地复跑固件 ELF 构建
5. 提交并创建 PR
6. 检查 GitHub Actions 是否通过

## 验证方式
- 主机：`ctest --test-dir build --output-on-failure`
- 固件：`cmake --build build-fw`
- GitHub Actions：`Host CMake tests` 与 `Firmware ELF build` 均通过

## 未决问题
- 后续使用真实 ARM GNU Toolchain 后，可以替换 Zig 验证 job 或增加第二个 job
