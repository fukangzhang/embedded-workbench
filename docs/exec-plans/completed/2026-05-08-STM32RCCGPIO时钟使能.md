# STM32 RCC GPIO 时钟使能

## Goal
新增一个可主机测试的 STM32 RCC GPIO 端口时钟使能模块，为后续真实板级初始化串起“开端口时钟 -> 配 GPIO 输出模式 -> 写 BSRR 输出电平”的顺序。

## Scope
- 新增 `stm32_rcc_gpio_clock` 接口和实现。
- 使用端口名查找 RCC GPIO 时钟位。
- 对目标端口设置 enable register 中对应 bit。
- 增加主机测试覆盖 PA/PB 时钟开启、重复开启、未知端口、空指针和非法绑定。
- 更新学习笔记、设计边界和学习 README。

不在本任务中做：
- 真实 RCC 寄存器地址绑定。
- 完整系统时钟树配置。
- GPIO 初始化入口串联。
- 板上下载验证。

## Steps
1. 定义 RCC GPIO 时钟绑定表和上下文。
2. 实现 `stm32_rcc_enable_gpio_port_clock`。
3. 增加主机测试并接入 CMake。
4. 补充学习/设计文档。
5. 运行主机测试和固件构建验证。
