# STM32F401RE USART2 绑定

## 这一步做了什么？

本步骤把 STM32F401RE 上和 USART2 有关的固定事实记录到绑定层：

- `RCC_APB1ENR` 地址。
- `USART2` 寄存器 base address。
- USART2 时钟 enable bit。
- PA2 是 USART2 TX。
- PA3 是 USART2 RX。
- PA2/PA3 使用 AF7 连接 USART2。

## 为什么叫绑定？

通用 driver 不应该写死“USART2 地址是 0x40004400”。因为换成别的芯片或别的串口时，这个地址可能不同。

所以项目把“通用操作”和“具体芯片事实”分开：

```text
stm32_usart
  -> 通用 USART 寄存器操作

stm32f401re bindings
  -> STM32F401RE 的真实地址和 pin/AF 事实
```

## 代码怎么读？

建议按这个顺序：

1. `drivers/include/embedded_workbench/stm32f401re_gpio_bindings.h`
   - 看新增的 `STM32F401RE_RCC_APB1ENR_ADDRESS`。
   - 看 `STM32F401RE_USART2_BASE_ADDRESS`。
   - 看 USART2 的 PA2/PA3 和 AF7 常量。

2. `drivers/src/stm32f401re_gpio_bindings.c`
   - 看 `usart_clock_peripherals` 如何绑定 USART2 bit17。
   - 看 `stm32f401re_usart2_tx_pin` 和 `stm32f401re_usart2_rx_pin`。

3. `tests/test_stm32f401re_gpio_bindings.c`
   - 注意测试只把指针转成整数比较地址。
   - 不要在主机上解引用这些地址。

## 嵌入式知识点

USART2 需要两类硬件连接同时正确：

- RCC：USART2 外设本身要有时钟。
- GPIO：PA2/PA3 要切到 AF7，让引脚连接到 USART2。

如果只配置 USART2 寄存器，但 PA2/PA3 没有 AF7，串口不会正常从引脚输出或输入。
