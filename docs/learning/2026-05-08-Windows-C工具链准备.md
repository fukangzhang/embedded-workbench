# Windows C 工具链准备

## 为什么现在卡在工具链？
这个项目使用 `CMake` 描述构建流程，但 `CMake` 本身不编译代码。它需要配合一个真正的 C 编译器，例如：

- MSVC：Visual Studio 或 Build Tools 提供
- GCC：MinGW 或 MSYS2 提供
- Clang：LLVM 提供

当前环境里暂时没有找到：

- `cmake`
- `gcc`
- `clang`
- `cl`

所以现在可以写代码和文档，但还不能完成真正的编译验证。

## 推荐安装路线
为了后续同时兼顾嵌入式和主机测试，推荐优先使用：

1. CMake
2. Ninja
3. ARM GNU Toolchain
4. 一个主机 C 编译器

在 Windows 上比较稳的路线是安装 Visual Studio Build Tools，并勾选 C++ 桌面开发工具链。虽然我们主要写 `C`，但 MSVC 的 C 编译器随这个工具链提供。

也可以使用 MSYS2 或 MinGW，但后续接 STM32 时仍然需要单独安装 ARM 工具链。

## 后续验证命令
工具链准备好后，回到项目根目录运行：

```powershell
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

如果这些命令都通过，说明主机侧工程骨架已经闭环。
