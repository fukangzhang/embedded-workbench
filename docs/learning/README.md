# 学习笔记入口

这个目录用于记录项目推进过程中必须理解的嵌入式背景知识。目标不是写一本完整教材，而是把当前代码为什么这样设计、背后涉及哪些概念、面试时可以怎么讲，整理成可以随时回看的短文档。

## 阅读方式
- 先看当前正在做的模块对应笔记
- 再回到代码，看接口和测试如何体现这些概念
- 不追求一次看懂全部，后续每做一个小功能都会补充相关知识点

## 当前建议理解顺序
1. 项目整体路线：先理解为什么采用主机仿真优先
2. CMake 与 C 工程骨架：理解代码如何被编译、链接和测试
3. 分层架构：理解 `bsp -> drivers -> app` 的依赖方向
4. 传感器抽象：理解真实硬件和模拟数据如何用同一套接口接入
5. 告警状态机：理解阈值、恢复条件、状态切换为什么适合测试驱动
6. 通信协议：理解串口命令、帧格式和参数配置
7. FreeRTOS 任务：理解采集、处理、通信、告警任务如何协作

## 笔记规则
- 每篇只解释当前阶段真正用到的概念
- 尽量配合本项目代码举例
- 记录“为什么这样做”，不只记录“怎么写”
- 可以补充面试表达，但不把简历包装放在代码之前
