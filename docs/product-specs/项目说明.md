# 项目说明

## 项目名称
基于 `STM32/MCU + FreeRTOS` 的环境监测与告警控制终端

## 项目定位
这是一个面向求职展示的嵌入式软件项目。项目重点不在“硬件堆料”，而在于展示一个初级到中级嵌入式软件工程师应具备的工程能力，包括：

- 分层设计能力
- 任务拆分能力
- 通信与协议处理能力
- 传感器数据采集与处理能力
- 状态机与告警控制逻辑设计能力
- 测试与验证意识

## 核心功能
- 模拟温湿度、光照、烟雾等传感器输入
- 使用任务模型管理采集、处理、通信和告警逻辑
- 实现阈值判断、告警触发、恢复条件和状态切换
- 提供串口通信接口，用于输出状态、接收配置命令
- 为未来接入真实 `STM32` 硬件保留清晰接口

## 开发策略
项目先采用“主机仿真优先”的方式推进：

1. 先把协议、状态机、数据处理逻辑做对
2. 再把接口抽象清楚
3. 最后逐步替换为真实硬件实现

这样做的原因是，在没有开发板的情况下，依然可以先完成最有含金量的软件部分。

## 适合写进简历的表达方向
- 基于 `STM32/MCU + FreeRTOS` 设计环境监测与告警控制系统的软件架构
- 实现传感器抽象、告警状态机、串口通信和参数配置逻辑
- 采用分层设计与主机仿真方式，提高无硬件阶段的开发效率和可测试性
- 为后续目标板移植预留 `BSP` 与驱动替换接口

## 当前阶段目标
第一阶段先完成项目定义、模块边界、第一批核心接口与仿真思路，不急着一口气把所有功能写完。
