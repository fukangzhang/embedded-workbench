# STM32F401RE GPIO 地址绑定边界

## 决策
新增 `stm32f401re_gpio_bindings`，集中提供 STM32F401RE 的 RCC/GPIO 地址和 PA/PB 绑定表。

## 职责
- 暴露 `RCC_AHB1ENR` 地址。
- 暴露 GPIOA/GPIOB 配置寄存器块地址。
- 暴露 GPIOA/GPIOB BSRR 地址。
- 暴露 PA/PB 到 RCC enable bit 的绑定。

## 不负责
本模块不负责：

- 解引用真实寄存器地址。
- 开启时钟、配置 GPIO 或写 BSRR。
- 板级启动顺序编排。
- CMSIS/HAL 头文件适配。
- 板上下载验证。

## 为什么这样分
地址绑定是芯片相关事实，GPIO 配置/输出是可复用动作。分开以后：

- `stm32_gpio_config` 不需要知道 F401RE 地址。
- `stm32_gpio_output` 不需要知道 F401RE 地址。
- `firmware/src/main.c` 后续可以选择模拟寄存器或真实绑定。

## 当前验证边界
主机测试只把返回指针转为整数比较地址值，不会访问这些地址。通过测试不代表真实硬件访问安全，也不代表板上 GPIO 行为正确。
