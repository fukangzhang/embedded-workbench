# 板级数字输出后端边界

## Context
项目已经有 `digital_output` 接口，也有 board profile 记录告警 LED、蜂鸣器和执行器引脚。下一步需要一个后端来实现 `digital_output_ops_t.write`，但当前还不应该直接绑定 STM32 HAL 或寄存器。

## Decision
新增 `board_digital_output`，作为 profile-backed 后端。

它负责：

- 识别 `board_profile_t` 中的三类告警输出引脚
- 记录每个引脚的当前电平
- 拒绝不属于当前 profile 的未知输出脚

## Consequences
- 可以在主机侧测试输出后端行为。
- 真实 GPIO 后端可以后续替换或并行新增。
- 当前模块不处理 GPIO 初始化、端口时钟、输出速度、上下拉等硬件细节。
- 当前模块记录状态，不代表板上电平已经变化。
