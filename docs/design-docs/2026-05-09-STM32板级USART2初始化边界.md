# STM32 板级 USART2 初始化边界

## 背景

前面已经分别完成了 GPIO AF 配置、USART RCC 时钟、USART 寄存器 helper 和 STM32F401RE USART2 绑定。它们还是分散的小积木，真实串口链路需要一层板级初始化把这些步骤按正确顺序串起来。

## 决策

新增 `stm32_board_usart2_init` 作为板级编排入口：

```text
STM32F401RE USART2 bindings
  -> GPIOA clock
  -> PA2/PA3 AF7
  -> USART2 APB1 clock
  -> USART2 8N1 config
```

这个函数接收已经初始化好的 context 和 USART config，不在内部创建全局状态。这样主机测试可以把真实寄存器替换成普通变量，验证初始化顺序和寄存器写入结果。

## 边界

本模块负责：

- 选择 STM32F401RE 上 USART2 的 TX/RX 引脚。
- 把 PA2/PA3 配置成 AF7。
- 打开 GPIOA 时钟。
- 打开 USART2 时钟。
- 调用 USART helper 配置 8N1。

本模块不负责：

- 逐字节收发。
- 解析串口命令。
- 把串口字节接到 `serial_command_service`。
- 在 `firmware/src/main.c` 中启用真实板卡路径。
- 处理 DMA、中断或 FreeRTOS 任务。

## 风险

当前实现是“顺序执行、遇错返回 false”。如果前面步骤已经写了 GPIO 寄存器，后面 USART2 时钟缺失导致失败时，不会自动回滚前面写入。这和现有 `stm32_board_gpio_init` 的行为一致，适合初始化阶段；后续如果要做运行时重配置，再单独设计回滚策略。

## 后续

下一步可以把这个板级初始化接入固件自检或受编译开关控制的真实 USART2 初始化路径，然后再把轮询收发接到 `serial_command_service`。
