# STM32 RCC GPIO 时钟边界

## 决策
新增 `stm32_rcc_gpio_clock`，只负责设置 RCC GPIO 端口时钟 enable bit，不负责 GPIO 配置、GPIO 输出或完整系统时钟树。

## 职责
- 根据端口名查找 RCC GPIO clock binding。
- 校验 enable bit 是否在 0..31 范围内。
- 对 enable register 设置对应 bit。
- 对空指针、未知端口和非法绑定返回失败。

## 不负责
本模块不负责：

- 系统主时钟/PLL 配置。
- APB/AHB 分频配置。
- GPIO `MODER/OTYPER/OSPEEDR/PUPDR` 配置。
- GPIO `BSRR` 输出写入。
- 真实 RCC 寄存器地址绑定和板上验证。

## 为什么这样分
RCC 时钟、GPIO pin 配置和 GPIO 输出是不同阶段。拆开后：

- RCC 模块专注验证 enable bit 设置。
- GPIO config 模块专注验证 pin 配置寄存器。
- GPIO output 模块专注验证 BSRR 输出写入。

后续 board init 可以按顺序组合这些模块，而不是把所有寄存器操作塞进一个不可测试的大函数。

## 当前验证边界
主机测试用普通变量模拟 RCC enable register，只验证 bit 操作，不证明真实 RCC 地址、芯片时钟树或板上 GPIO 行为。
