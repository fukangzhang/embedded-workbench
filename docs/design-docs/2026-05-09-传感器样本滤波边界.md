# 传感器样本滤波边界

## 背景

真实传感器接入后，原始采样可能抖动。如果直接把每次原始值送入阈值判断，告警状态可能在临界点附近频繁跳变。

## 决策

新增 `sensor_sample_filter` driver 模块，用整数权重做一阶平滑：

```text
filtered = previous + (input - previous) * alpha
```

其中 `alpha` 使用：

```text
alpha_numerator / alpha_denominator
```

不用 `float`，便于 MCU 固件和主机测试保持一致。

## 边界

- 当前模块只提供能力，不接入 `sensor_acquisition` 或 FreeRTOS 任务。
- `filtered_sensor_source` 已经提供可选组合层，但不会自动改变任何运行链路。
- 首个合法样本直接透传，作为滤波器初始值。
- 输入样本必须通过 `sensor_sample_is_valid`。
- 输出仍需满足 `sensor_sample_is_valid`。
- 整数除法会截断小数，这是当前固定点实现的有意取舍。

## 后续

- 决定滤波接入位置：采集任务内部、环境处理任务前，或装配时使用 `filtered_sensor_source` 包装原始 source。
- 真实传感器型号确定后，再决定默认 `alpha`。
- 如果需要更强平滑或响应速度，可以扩展为滑动平均或多级滤波。
