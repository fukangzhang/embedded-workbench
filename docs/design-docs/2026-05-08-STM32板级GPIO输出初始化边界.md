# STM32 板级 GPIO 输出初始化边界

## 决策
新增 `stm32_board_gpio_init` 作为板级 GPIO 输出初始化编排层，负责按 `board_profile` 初始化项目关心的告警输出引脚。

## 职责
- 读取 `board_profile_t` 中的 `alarm_led`、`alarm_buzzer`、`alarm_actuator`。
- 对每个 pin 先调用 RCC GPIO 时钟使能。
- 再调用 GPIO 输出配置。
- 支持调用者传入输出配置；为空时使用默认 GPIO 输出配置。
- 任一步失败时停止后续初始化并返回失败。

## 不负责
本模块不负责：

- 真实 RCC/GPIO 寄存器地址绑定。
- GPIO 初始电平写入。
- 告警状态到输出电平的业务映射。
- FreeRTOS task 启动。
- 板上下载验证。

## 为什么这样分
RCC、GPIO 配置和 GPIO 输出动作已经分别独立。板级初始化层只做编排：

```text
board_profile
  -> stm32_rcc_gpio_clock
  -> stm32_gpio_config
```

这样后续真实板级启动入口可以复用这层，而 app 层继续只关心告警输出策略。

## 当前验证边界
主机测试验证初始化顺序、配置结果、重复端口和失败停止行为。它不能证明真实地址绑定正确，也不能证明真实硬件已经动作。
