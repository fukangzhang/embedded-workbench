# 告警输出节拍边界

## Context
`alarm_output_command_t` 已经包含 `period_ms`，但在此之前它只用于展示，没有独立的节拍规则。

后续 FreeRTOS 告警输出任务需要根据时间刷新 indicator 电平，因此需要先固定纯逻辑行为。

## Decision
新增 `alarm_output_timing`，提供 `alarm_output_indicator_is_on`。

当前约定：

- `period_ms` 表示完整闪烁周期。
- indicator 在周期前半段点亮。
- indicator 在周期后半段熄灭。
- `indicator=off` 始终熄灭。
- 非 off 且 `period_ms=0` 表示常亮。

## Consequences
- 节拍规则可在主机侧测试。
- FreeRTOS 只需要提供 elapsed time 和周期性调用。
- 当前模块不处理输出写入，也不处理计时来源。
