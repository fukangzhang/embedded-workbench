# 告警输出数字输出适配器边界

## Context
`alarm_output_sink` 属于应用层输出目标，`digital_output` 属于驱动层数字输出抽象。两者需要连接，但不能让驱动层反向依赖告警业务。

## Decision
新增 `alarm_output_digital_sink`，放在 `app` 层。

它负责：

- 把 indicator 映射到 `profile->alarm_led`
- 把 buzzer 映射到 `profile->alarm_buzzer`
- 把 actuator 映射到 `profile->alarm_actuator`
- 调用 `digital_output_write`

## Consequences
- `drivers` 仍然不知道告警状态和告警输出语义。
- `app` 可以通过适配器选择具体输出后端。
- `period_ms` 当前不处理，后续由调度或定时器任务实现闪烁节拍。
- 真实 STM32 GPIO 实现仍然只需要实现 `digital_output_ops_t.write`。
