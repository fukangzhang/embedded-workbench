# STM32 GPIO 初始化配置边界

## 决策
新增 `stm32_gpio_config`，只负责把目标 pin 配置为 STM32 GPIO 输出模式，不负责实际输出电平，也不负责 RCC 时钟。

## 职责
- 根据 `board_pin_t.port` 查找 GPIO 配置寄存器块。
- 将 `MODER` 目标 pin 配为 output。
- 根据配置写入 `OTYPER`、`OSPEEDR`、`PUPDR`。
- 对未知端口、非法 pin、非法枚举值和空指针返回失败。

## 不负责
本模块不负责：

- RCC GPIO 端口时钟开启。
- 真实 STM32 寄存器基地址绑定。
- HAL/CMSIS 头文件适配。
- BSRR 高低电平写入。
- 板上下载和示波器/LED 观察验证。

## 为什么这样分
GPIO 初始化和 GPIO 输出动作是两个不同阶段：

- 初始化阶段决定 pin 的工作方式。
- 输出阶段决定 pin 当前是高电平还是低电平。

拆开后，`stm32_gpio_config` 可以专注验证配置寄存器位操作，`stm32_gpio_output` 可以专注验证 BSRR 写入。后续真实板级启动流程可以按顺序调用二者。

## 当前验证边界
主机测试用普通变量模拟 GPIO 配置寄存器，验证位操作是否正确。它不能证明真实芯片时钟已经开启，也不能证明真实 pin 已经输出电平。
