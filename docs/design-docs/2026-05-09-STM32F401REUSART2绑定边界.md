# STM32F401RE USART2 绑定边界

## 背景

USART helper、GPIO alternate function helper 和 RCC USART clock helper 都是通用模块。要初始化真实 NUCLEO-F401RE 上的 USART2，还需要一层芯片/板级事实绑定。

## 决策

在现有 `stm32f401re_gpio_bindings` 中补充 USART2 相关绑定：

- `RCC_APB1ENR` 地址。
- `USART2` base address。
- `USART2` 在 APB1ENR 的 enable bit。
- PA2 作为 USART2 TX。
- PA3 作为 USART2 RX。
- USART2 GPIO alternate function 为 AF7。

## 边界

本绑定层负责：

- 保存 STM32F401RE 相关地址和常量。
- 返回静态表和板级 pin 描述。
- 允许主机测试比较地址数值。

本绑定层不负责：

- 解引用真实 STM32 地址。
- 打开 RCC 时钟。
- 配置 PA2/PA3 AF7。
- 配置 USART2 BRR/CR1。
- 连接 `serial_command_service`。

## 后续

下一步可以新增 `stm32_board_usart2_init`：

```text
stm32f401re bindings
  -> enable GPIOA clock
  -> PA2/PA3 AF7
  -> enable USART2 clock
  -> configure USART2 8N1
```
