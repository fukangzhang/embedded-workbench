# 序列传感器来源边界

## 背景

`sensor_source_t` 已经定义了“读取一帧 sample”的统一接口，但只有接口还不够。主机仿真需要一个可重复、可测试的 sample 来源，用来演示 normal、warning、alarm、recovery 这些状态变化。

## 决策

新增 `sequence_sensor_source_t`：

- 持有一段 `sensor_sample_t` 数组引用。
- 每次读取返回下一帧 sample。
- 读到末尾后默认失败。
- 可通过 `repeat_last` 选择重复最后一帧。

`host_sim` 的 demo 样本改为通过 `sensor_source_read` 读取，而不是直接遍历裸数组。

## 边界

本阶段负责：

- 提供一个可复用的仿真/测试 sample source。
- 验证顺序读取、末尾失败、重复最后一帧、非法 sample 拒绝。
- 让 `host_sim` demo 使用 `sensor_source_t` 接口。

本阶段不负责：

- 真实传感器驱动。
- 随机噪声、滤波或复杂传感器模型。
- FreeRTOS 调度器板上运行验证。

## 后续

后续可以把 sequence source 用在更完整的主机仿真脚本里，或增加真实硬件 source，例如 I2C 温湿度传感器、ADC 光照输入、烟雾传感器输入。
