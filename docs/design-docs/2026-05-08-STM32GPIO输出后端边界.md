# STM32 GPIO 输出后端边界

## 决策
新增 `stm32_gpio_output` 作为 `digital_output_controller_t` 的一种后端，只负责把数字输出写入 STM32 `GPIOx_BSRR`。

## 职责
- 根据 `board_pin_t.port` 查找 GPIO 端口绑定。
- 根据 `board_pin_t.pin` 生成 BSRR bit。
- `HIGH` 写 BSRR 低 16 位。
- `LOW` 写 BSRR 高 16 位。
- 对空指针、未知端口、非法 pin 做失败返回。

## 不负责
本模块不负责：

- RCC 时钟开启。
- GPIO mode/pull/speed/output type 配置。
- 真实寄存器基地址选择。
- HAL/CMSIS 类型适配。

这些内容后续应放在更明确的 BSP 初始化或 STM32 平台适配层里。

## 为什么这样分
`digital_output` 是通用抽象，`stm32_gpio_output` 是 STM32 写寄存器后端。把 BSRR 写法独立出来后：

- app 层不用知道 STM32 寄存器。
- 主机测试可以用普通变量模拟 BSRR。
- 后续真实硬件只需提供端口绑定和初始化流程。

## 当前验证边界
当前测试验证的是寄存器写值是否正确，不验证真实 GPIO 是否已经配置成输出模式，也不验证板上电气连接。
