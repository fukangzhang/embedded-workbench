# 串口行缓冲边界

## 决策

新增 `serial_line` 模块，把逐字节输入组装成一行文本命令。

## 职责

- 保存当前未完成的一行。
- 识别 `\n` 和 `\r` 行结束。
- 忽略空行。
- 在完整行产生时复制到调用者提供的输出缓冲区。
- 在内部缓冲或输出缓冲不足时返回溢出状态并复位。

## 不负责

本模块不负责：

- 读取真实 UART 寄存器。
- 配置 USART2 波特率、GPIO 复用或中断。
- 解析命令语义。
- 执行命令或格式化响应。
- 管理 FreeRTOS queue。

## 为什么这样分

串口输入链路至少有三层：

```text
byte stream -> line framing -> command parsing
```

`command_parser` 已经处理完整字符串。如果把逐字节缓冲逻辑塞进 parser，后续 UART、USB CDC、主机 stdin 都会和解析规则耦合在一起。

单独拆出 `serial_line` 后：

- UART 中断或通信任务只需要逐字节调用 `serial_line_feed`。
- parser 继续只处理完整行。
- 主机测试能覆盖换行、空行和溢出，不需要真实硬件。

## 验证边界

当前 `tests/test_serial_line.c` 覆盖：

- LF 完成行。
- CRLF 只产生一行。
- 空行忽略。
- 缓冲区溢出复位。
- 空指针和非法容量防御。

它不覆盖真实 UART 时序、中断并发或 DMA 接收，这些属于后续 USART 接入任务。
