# 固件 USART2 命令 Pump 自检边界

## 决策

把 `firmware_usart2_command_service_self_check` 中手写的逐字节 feed 循环替换为 `serial_command_pump_poll`。

## 职责

本阶段负责：

- 在固件入口中引用 `serial_command_pump`。
- 用一个小的 text reader callback 模拟 `STATUS?\n` 输入。
- 验证 pump 能把 reader 字节喂给 `serial_command_service`。
- 验证响应仍然通过 `stm32_usart_serial_io_write` 写到模拟 USART2 `DR`。

## 不负责

本阶段不负责：

- 真实 USART2 RX 轮询。
- 无限主循环中的命令处理。
- FreeRTOS task 调度。
- 中断、DMA 或 ring buffer。
- 板上 USB-UART 实测。

## 后续

下一步可以新增受编译开关保护的真实 USART2 polling loop，让 reader callback 从 `stm32_usart_serial_io_read_byte` 读取真实 USART2 字节。
