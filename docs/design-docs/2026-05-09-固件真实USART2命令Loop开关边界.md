# 固件真实 USART2 命令 Loop 开关边界

## 决策

新增默认关闭的 CMake 开关 `EW_FIRMWARE_USE_REAL_STM32_USART2_COMMAND_LOOP`。打开后，固件会使用 STM32F401RE 的真实 RCC/GPIO/USART2 地址初始化 USART2 命令轮询链路。

## 职责

本阶段负责：

- 配置 GPIOA、PA2/PA3 AF7、USART2 APB1 clock 和 USART2 8N1。
- 初始化 `stm32_usart_serial_io`。
- 初始化 `serial_command_service`。
- 在固件 idle loop 中调用 `serial_command_pump_poll`。
- 在 CI 中增加“真实 USART2 命令 loop 编译检查”。

## 不负责

本阶段不负责：

- 默认启用真实 USART2 loop。
- 板上 USB-UART 实测。
- 中断、DMA、ring buffer。
- FreeRTOS task 化串口命令服务。
- 动态传感器采样更新。

## 验证边界

CI 只证明打开该开关时固件能编译和链接。因为 CI 不运行在 STM32 板上，所以它不能证明电脑串口助手已经能交互。

真实硬件验证必须在 NUCLEO-F401RE 上单独执行，并记录串口工具、波特率、命令输入和响应输出。
