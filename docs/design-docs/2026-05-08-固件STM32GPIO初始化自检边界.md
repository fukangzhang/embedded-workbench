# 固件 STM32 GPIO 初始化自检边界

## 决策
在 `firmware/src/main.c` 中加入 STM32 GPIO 初始化链路自检，但使用模拟寄存器变量，不绑定真实硬件地址。

## 职责
- 在固件入口中初始化 RCC/GPIO 模拟寄存器。
- 通过 `stm32_board_gpio_init_alarm_outputs` 初始化 profile 中的告警输出引脚。
- 检查 RCC enable bit 和 GPIO MODER output 位。
- 将检查结果纳入 `firmware_self_check`。

## 不负责
本阶段不负责：

- 真实 `RCC_AHB1ENR` 地址绑定。
- 真实 `GPIOA/GPIOB` 地址绑定。
- GPIO 初始电平写入。
- 板上下载运行。
- FreeRTOS task 与真实 GPIO 后端绑定。

## 为什么这样分
固件 bring-up 可以分成两步：

1. 构建级自检：确认模块能链接、能调用、寄存器位操作符合预期。
2. 板上验证：绑定真实地址，下载到开发板，观察 LED/蜂鸣器/执行器。

当前处在第一步。这样做能在没有硬件验证前先降低集成风险。

## 当前验证边界
本阶段通过固件构建验证自检代码能进入目标 ELF，但不会实际运行在 STM32 板上。它是“固件链接和调用路径验证”，不是“硬件行为验证”。
