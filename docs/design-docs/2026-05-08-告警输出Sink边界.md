# 告警输出 Sink 边界

## Context
项目已经有 `alarm_state` 和 `alarm_output`：

- `alarm_state` 判断当前安全状态。
- `alarm_output` 把状态映射成指示灯、蜂鸣器、执行器和周期。

下一步需要让 FreeRTOS 告警输出任务能把这个结果交给硬件，但当前还没有真实 GPIO 驱动和目标板引脚映射。

## Decision
新增应用层 `alarm_output_sink` 接口，作为输出命令和真实硬件之间的边界。

`alarm_output_sink` 暴露三个回调：

- `set_indicator`
- `set_buzzer`
- `set_actuator`

FreeRTOS 告警输出任务只依赖这个 sink。真实 GPIO、蜂鸣器或继电器实现后续再接入。

## Consequences
- 主机测试可以用 fake sink 验证输出命令是否被正确应用。
- `alarm_state` 和 `alarm_output` 不需要包含 STM32 GPIO 细节。
- 后续如果更换开发板，只需要调整 sink 的具体实现。
- 当前 sink 是同步调用，暂不处理硬件失败重试或输出节拍调度。
