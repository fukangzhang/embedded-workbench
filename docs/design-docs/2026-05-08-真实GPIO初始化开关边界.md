# 真实GPIO初始化开关边界

## 决策

新增 `EW_FIRMWARE_USE_REAL_STM32_GPIO_INIT`，用于在固件构建时显式启用 STM32F401RE 真实 GPIO/RCC 地址初始化路径。

## 默认行为

默认值为 `OFF`。默认固件仍然只用模拟寄存器运行 `firmware_stm32_gpio_init_self_check`，保证 CI 和本地构建不会访问真实硬件地址。

## 开关打开后

固件会额外执行：

```text
stm32f401re_gpio_bindings
  -> stm32_rcc_gpio_clock
  -> stm32_gpio_config
  -> stm32_board_gpio_init
```

也就是使用真实 `RCC_AHB1ENR`、`GPIOA`、`GPIOB` 地址初始化 `board_profile` 中的告警 LED、蜂鸣器和执行器引脚。

## 不负责

本开关不负责：

- 板上下载流程
- 运行时调试输出
- 证明 GPIO 实际电平变化
- 证明外部 LED、蜂鸣器、执行器接线正确
- 替代后续的板级 bring-up checklist

## 验证边界

CI 新增开启该开关的固件 ELF 构建。这个构建只覆盖：

- 编译宏是否正确传入
- 真实地址初始化路径是否能编译链接
- 绑定层和初始化模块之间的类型/符号是否匹配

它不运行 ELF，因此不验证真实寄存器访问结果。
